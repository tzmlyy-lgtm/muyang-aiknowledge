一、站点档案

  • 品牌：沐阳 · 数据与 AI 学习图谱（logo：向阳小人水粉徽标 + 思源宋体字标）
  • 技术栈：纯静态单页应用 —— 一个 index.html + 10 个 JS（无框架、无构建），marked.js 渲染 Markdown
  • 线上地址：CloudStudio 托管 1f8f30cd538541999e18b00ddaf85e17.app.workbuddy.host；GitHub Pages 仓库已备好（tzmlyy-lgtm.github.io），提供 Token 即可推送
  • 视觉体系：厚涂水粉/水彩纸质感 —— 暖米白画布 + 纸张颗粒噪声 + 笔刷扫痕，群青蓝点睛，各视图配专属水粉 hero 插画（WebP，总量约 1.1MB）
  • 路由：hash 路由（#briefing、#trends …），每个视图独立可分享 URL，标题随视图动态变化

七、增强路线图（新思路）

P0 · 短期秋招刚需 + 立竿见影

  • 作品集页面（最强推荐）：新增「💼 作品集」视图——把站内 16 个练手项目、市调赛/大创/三创经历、奇安信 Q-GPT 实习产出整理成可展示的案例卡（背景→方法→产出→链接）。秋招投递时直接甩链接，比附件简历更有说服力，且和站点「学习→实战→作品」的叙事完全契合
  • 全站搜索（Ctrl+K）：一个搜索框聚合知识点/笔记/资料/晨报存档——数据全部在本地 JS 里，纯前端模糊匹配即可实现，约 100 行代码，体验提升极大
  • GitHub Pages 上线：仓库已备好，提供 Token 后推送 → 获得独立域名 tzmlyy-lgtm.github.io，摆脱 workbuddy 子域，SEO 收录正式生效
  • PWA 化：加 manifest + Service Worker → 手机「添加到主屏幕」像 App 一样打开，晨报离线可读

P1 · 中期学习闭环 + 数据特色

  • 学习进度追踪：知识点打卡（已学/在学/想学），生成掌握度进度条与学习热力图——把「图谱」从静态清单变成个人成长记录
  • AI 周报：每周日把 7 天晨报聚合成「本周 AI 大事记」Top10（按版块加权 + 去重），可由 GitHub Actions 自动生成快照——统计人做信息聚合，正是专业对口
  • 数据集练习区：新增分类收录 Kaggle/天池/政府开放数据的入门数据集 + 配套分析思路——应用统计学生的练手弹药库，站内其他模块都没有覆盖这块
  • 收藏导出：一键把收藏夹导出为 Markdown/剪贴板，方便写周报或笔记软件归档
  • 晨报知识库再同步：资料库表有新增后说一声即可重跑导入流程；或升级为 GitHub Actions 定时拉接口 → 自动 commit 到 brief-library-data.js（彻底自动化）

P2 · 长期进阶玩法

  • 站内 AI 学习助手（RAG）：把 45 个知识点 + 21 篇笔记 + 272 条存档做成检索上下文，接一个大模型 API 做「问沐阳」——你的奇安信 Q-GPT 经验正好用来设计评测 BadCase，站点本身成为面试作品
  • 访问分析仪表盘：自建轻量统计（无 Cookie 的简单计数），用站内学到的可视化技能做一个「沐阳运营看板」——既是功能也是作品集素材
  • 多设备同步：收藏/学习进度接 Supabase 等免费后端，手机收藏电脑看
  • 测验增强：错题本 + 间隔复习（艾宾浩斯提醒）+ 按知识点出题

八、已知边界与注意事项

  • 收藏/进度仅存浏览器本地：换设备/清缓存会丢失（P2 多设备同步可解）
  • 晨报知识库是静态快照（截至 09-12，272 条）：资料库表更新后需手动触发再同步
  • 在线编程依赖第三方 CDN 运行时：极少数内网环境可能加载失败
  • 网址：当前为 workbuddy.host 子域，域名曾变更过（.link→.host），分享链接以最新为准；GitHub Pages 上线后彻底稳定
  • SEO 生效前提：结构化数据已就位，但 hash 路由对搜索引擎收录弱于多页面路由；若追求收录效果，P0 的 GitHub Pages 上线后可评估拆分静态多页
